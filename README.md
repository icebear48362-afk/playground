# playground

브라우저에서 바로 실행되는 작은 미니 프로젝트 모음입니다. 각 폴더는 의존성 없이 `index.html`을 여는 것만으로 동작합니다.

## 프로젝트

- [`particle-playground/`](particle-playground/index.html) — 마우스/터치로 그리는 파티클 놀이터
- [`pomodoro-tasks/`](pomodoro-tasks/index.html) — 뽀모도로 타이머 + 할 일 목록
- [`snake-game/`](snake-game/index.html) — 스네이크 게임

## 실행 방법

각 폴더의 `index.html`을 브라우저로 열면 됩니다. 별도 빌드나 설치 과정이 없습니다.
